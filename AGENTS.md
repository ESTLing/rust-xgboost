# AGENTS.md

Project overview and conventions for AI agents working on this codebase.

## What is this?

Rust bindings for [XGBoost](https://xgboost.ai) — two crates:
- `xgboost-rs` (`xgb` crate) — high-level safe API (Booster, DMatrix, training, prediction)
- `xgboost_lib-sys` (`xgboost-sys` crate) — low-level FFI bindings generated by bindgen

## Key design decisions

### API: Flat string key-value, like Python

Parameters are `&[(&str, &str)]` pairs — no structs, no builders, no enums for parameter names.
Users copy parameter names directly from [XGBoost docs](https://xgboost.readthedocs.io/en/latest/parameter.html).

```rust
Booster::train(
    &[("max_depth", "2"), ("eta", "1.0"), ("objective", "binary:logistic")],
    &dtrain,
    10,
    Some(&[(&dtest, "test")]),
)?;
```

### Build: PyPI wheel, no system dependencies

- `xgboost-sys/build.rs` downloads XGBoost 3.2.0 shared library from PyPI wheel at build time
- Headers downloaded from GitHub raw, SHA256-verified
- No cmake, ninja, libomp, clang, or submodules needed
- Set `XGBOOST_VERSION` env var to use a different version
- Set `RUST_PYPI_INDEX` to use a PyPI mirror (e.g. Tsinghua for China)

### Windows: raw-dylib linking

Uses `#[link(kind = "raw-dylib")]` — generates import thunks directly, no `.lib` file needed.
Requires Rust 1.71+. On Linux/macOS, standard `dylib` linking is used.

### DMatrix: array_interface JSON protocol

XGBoost 3.2+ C API expects `__array_interface__` JSON (Python numpy protocol) for data parameters.
`XGDMatrixCreateFromDense`/`CreateFromCSR`/`CreateFromCSC` take JSON strings containing
memory pointers and shape info, not raw float/int pointers.

## Project conventions

- **Language**: All docs, comments, and commit messages in English
- **Shell**: Prefer Git Bash over PowerShell (user has Git for Windows)
- **MSRV**: Rust 1.71+ (for raw-dylib support)
- **XGBoost version**: Default 3.2.0, overridable via `XGBOOST_VERSION` env var
- **Safety**: No `unwrap()` in Drop impls, no `assert!` for null checks in release builds

## File map

```
src/lib.rs            — crate root, xgb_call! macro, path_to_c_str helper
src/booster.rs         — Booster: train, predict, save/load, eval
src/dmatrix.rs         — DMatrix: from_dense, from_csr, from_csc, load, save
src/error.rs           — XGBError, XGBResult
xgboost-sys/build.rs   — PyPI download, header verification, bindgen, raw-dylib injection
xgboost-sys/src/lib.rs — include! bindings.rs
examples/              — basic, generalised_linear_model, multiclass_classification
```
